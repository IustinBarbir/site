Task 4

What is the hardcoded password used for LDAP in the UserInfo.exe binary?

I used ILSpy in order to be able to open the file and read the code

There is the Ldap function

public LdapQuery()
{
    string password = Protected.getPassword();
    entry = new DirectoryEntry(
        "LDAP://support.htb",
        "support\\ldap",
        password
    );
    entry.set_AuthenticationType((AuthenticationTypes)1);
    ds = new DirectorySearcher(entry);
}

But there is also a Protected class, which contains the passowrd

internal class Protected
{
    private static string enc_password =
    "0Nv32PTwgYjzg9/8j5TbmvPd3e7WhtWWyuPsyO76/Y+U193E";

    private static byte[] key =
    Encoding.ASCII.GetBytes("armando");

    public static string getPassword()
    {
        byte[] array =
        Convert.FromBase64String(enc_password);

        byte[] array2 = array;

        for (int i = 0; i < array.Length; i++)
        {
            array2[i] =
            (byte)((uint)(array[i] ^
            key[i % key.Length]) ^ 0xDFu);
        }

        return Encoding.Default.GetString(array2);
    }
}

The encoding seems to be done as follows:

1. enc_password string is Base64 decoded and placed into a byte array

2. a 2nd byte array "array2" is created with the same value as "array"

3. in a loop, it goes through each charather in "array" and it does XOR with one letter of the key, then with the byte 0xDFu

4. it return the decrypted key

The decryption can be done using a python script

import base64
from itertools import cycle

enc_password = base64.b64decode(
"0Nv32PTwgYjzg9/8j5TbmvPd3e7WhtWWyuPsyO76/Y+U193E"
)

key = b"armando"
key2 = 223
res = ''

for e, k in zip(enc_password, cycle(key)):
    res += chr(e ^ k ^ key2)

print(res)
