Advent of Cyber — Day 2

Target: TryHackMe — Advent of Cyber (Day 2)

Overview

This challenge focused on analyzing web server logs to identify suspicious activity.

Accessing the Machine

I used my own VM and connected via SSH to elfmcblue@IP. A quick ls revealed the two files needed to answer the first questions.

Log Analysis

I initially tried using cat, but the webserver.log file was far too large. So instead, I used grep to filter relevant entries.

Searching for the keyword "list" returned too many results, but the word "naughty" was much more unique and helped identify the correct entry.

The suspicious request occurred on 18 November 2022, which was a Friday. I mistakenly entered date formats like 18.11.2022 or 18/11/2022 before realizing the answer needed to be the weekday.

From the logs, I also noticed that the initial GET request returned 404, indicating the item was not successfully retrieved—important information for later steps.

Identifying the Attacker

The attacker’s IP address was easy to find because it was the only unique IP present in the log entries.

Finding the Stolen File

Because the attacker eventually succeeded, the successful request would return 200 instead of 404.

Knowing the file was likely a .txt, I used the following command to narrow it down to one result:

grep ".txt" webserver.log | grep "200"

Retrieving the Flag

The flag format was given as THM{}. To find it, I searched recursively:

grep -r "THM{"

This revealed the flag and completed Day 2 of the challenge.
