Advent of Cyber — Day 3

Overview

Day 3 focuses on OSINT challenges. The tasks were straightforward and mostly involved collecting information from public sources.

Registrar Information

I started by looking up the registrar of the domain using whois. This provided the answer for the first question right away.

Finding the GitHub Repository

Next, I used a simple Google dork to locate the project's GitHub repository:

site:github.com "santagift.shop"

This immediately pointed me to the correct repo.

Hunting for Flags in the Code

Since TryHackMe flags almost always follow the format THM{}, I searched directly for it inside the repository using the browser's search function.

Inside config.php, I found the flag hidden in one of the variables.

QA Server Discovery

I accidentally found the QA server URL early while browsing the GitHub README. But even without that, searching for qa in config.php gives the same result.

Database Password

The database password was also stored in the same configuration file, making it easy to retrieve.
