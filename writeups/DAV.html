Webdav. I think I have heard about this before, and if I am not mistaken, this is a vulnerable service.

If I recall correctly, webdav was given as an example by the professor when I was preparing for the eJPT cert.

Searching for webdav on msfconsole gave me 60 results. So I was right, it is pretty known. Now, which one is the good one..

Looking for exploits, I found out that there are some default credentials for webdav:

wampp
xampp

Here, in the passwd.dav file there is:

Well, since we can run cat, we don't need to do anything to escalate privileges, just cat out the root flag. Going to assume the root flag is in the root directory, as usual:
