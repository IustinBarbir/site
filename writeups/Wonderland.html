Wonderland — Walkthrough

Target: TryHackMe — Wonderland

Overview

Fall down the rabbit hole and enter wonderland.

Goals:

  • Obtain the flag in user.txt
  • Escalate privileges and obtain the flag in root.txt

Initial Recon

I started by scanning the machine with Nmap:

nmap -sC $IP

The scan showed that ports 22 (SSH) and 80 (HTTP) were open. I checked the website, but there wasn’t much to see.

Directory Enumeration

Next, I used Gobuster to enumerate directories:

gobuster dir -e -u $IP -w /usr/share/wordlists/dirb/common.txt

Gobuster returned a few interesting results:

  • /img — containing alice_door.jpg, alice_door.png, white_rabbit_1.jpg
  • /index
  • /r — showing the text: "Keep Going." and the quote: “Would you tell me, please, which way I ought to go from here?”

Chasing the Rabbit

I continued enumerating deeper paths. Running Gobuster on $IP/r revealed /a. Repeating the process for /r/a revealed /b, and so on.

Eventually, the sequence spelled out RABBIT, which led me to a new page.

Finding Hidden Credentials

Checking the page source, I noticed a hidden HTML element:

<p style="display: none;">alice:HowDothTheLittleCrocodileImproveHisShiningTail</p>

This looked like a set of SSH credentials, so I tried them—and they worked.

SSH Access

After logging in, I listed the files in the home directory and saw root.txt (which I couldn’t read) and a Python script. I also didn’t have permission to access other users' folders inside /home.

Getting the User Flag

I got stuck for a while here and eventually looked for hints. Although I couldn’t read /root/root.txt, I assumed the user flag might be stored under /root. I tried:

cat /root/user.txt

That worked and gave me the user flag

Privilege Escalation

Next, I checked what I could run with sudo:

sudo -l

The output showed that I could run the Python script as the user rabbit.

Investigating the Python Script

I opened the script to understand what it did. After looking it over and doing some research, I realized that the script was vulnerable to library hijacking, which I could use to escalate privileges.
