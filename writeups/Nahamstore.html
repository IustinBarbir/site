NahamStore — Walkthrough

Target: TryHackMe — NahamStore

Overview

I heard that NahamStore is inspired by Juice Shop, so I wanted to try it out and see how far I could get. Before starting, I set up my /etc/hosts file so that nahamstore.thm points to the machine’s IP.

Initial Recon

I began with two scans, one with Nmap and one with Gobuster, to identify open ports and interesting directories.

nmap -sC -sV -T4 -A 10.10.24.192

Nmap revealed the following open ports:

  • 22/tcp — SSH (OpenSSH 7.6p1 Ubuntu)
  • 80/tcp — HTTP (nginx 1.14.0)
  • 8000/tcp — HTTP (nginx 1.18.0) with /admin disallowed in robots.txt

In parallel, I ran a Gobuster scan:

gobuster dir -u http://nahamstore.thm -w /usr/share/wordlists/dirb/common.txt

Gobuster discovered several endpoints:

  • /basket
  • /login
  • /register
  • /returns
  • /search
  • /robots.txt
  • /staff
  • /uploads

During this time, I also browsed the website using Burp Suite to map out how the site behaves.

Exploring the Staff Page

The /staff page was the most interesting early find. It exposed two staff names — Ben and Adam — and allowed file uploads. These looked like potential footholds.

Since NahamStore reminded me of Juice Shop, I immediately tried common SQL injection payloads on the login form, but none of them worked.

Weak Password Policy

While testing the registration process, I noticed that the website allows very weak passwords as long as they are at least 6 characters long. Even something like 000000 works. Definitely not a good security practice.

Attempting SSH Brute Force

Since SSH was open and I already had two usernames (ben and adam), I decided to try password brute forcing with Hydra. Unfortunately, this didn’t lead anywhere:

hydra -l ben -P /usr/share/wordlists/rockyou.txt ssh://10.10.24.192
hydra -l adam -P /usr/share/wordlists/rockyou.txt ssh://10.10.24.192

No valid passwords were found.

Moving On

After spending quite a bit of time on this room trying different attack vectors, exploring forms, testing uploads, and checking for possible flaws, I still couldn’t make meaningful progress. At some point, the room became more frustrating than educational, so I decided to pause it and continue with other challenges instead.
