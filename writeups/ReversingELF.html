Reversing ELF — Practice

Context: Taking a break from Advent of Cyber to prepare for the Bitdefender CTF by practicing binary reversing.

Starting Out

I wanted to work with ELF binaries since they are common in CTF challenges. Running the first file with:

./file

resulted in:

zsh: permission denied

I recognized this immediately from my Master's program, which was a small confidence boost.

Crackme 1 — Executable Permissions

Simply adding executable permissions fixes the issue:

chmod +x <file>

After that, running the file gives the first flag.

Crackme 2 — Password via strings

Running it shows a usage hint:

Usage: ./crackme2 password

Using strings reveals the hidden password:

strings crackme2 | grep -i secret

Entering it returns the second flag.

Crackme 3 — Base64 Decoding

This one required decoding a Base64 string:

ZjByX3kwdXJfNWVjMG5kX2xlNTVvbl91bmJhc2U2NF80bGxfN2gzXzdoMW5nNQ

Decoding it gives the flag.

Crackme 4 — Using gdb and strcmp

Adding executable permissions wasn’t enough — this binary required debugging. I used gdb:

info functions

I added a breakpoint at strcmp:

break *0x0000000000400520

Then ran the file with a test input and inspected registers:

info registers

Checking each register with:

x/s <register>

revealed the flag on the first try.

Crackme 5 — strncmp and ltrace

This time the binary used strncmp@plt. The flag was stored in the rsi register. Alternatively, ltrace made it straightforward:

ltrace ./crackme5

It printed all function calls, including:

strncmp("test", "<flag>", 28) = 37

revealing the hidden string.

Crackme 6 — IDA and ASCII Values

I opened the binary in IDA Free and inspected main, compare_pwd and my_secure_tests. The program contained multiple checks like:

if ( *a1 != 49 ) return -1;

Converting the numbers to ASCII spelled out the flag. I followed online guides for this one.

Crackme 7 — Bypassing Logic via Input

In IDA pseudocode I found:

else if ( v7[0] == 31337 ) {
    puts("Wow such h4x0r!");
    giveFlag();
}

Initially I wasn’t sure what v7 referred to, but then I noticed:

__isoc99_scanf("%u", v7)

So I simply entered 31337 before choosing any option in the menu — and it immediately returned the flag.

Crackme 8 — Integer Comparison

In IDA, before even decompiling, I saw the instruction:

cmp eax, 0CAFEF00Dh

Which corresponds to:

-889262067

And the pseudocode confirmed it:

if ( atoi(argv[1]) == -889262067 ) {
    puts("Access granted.");
    giveFlag();
}

Running the binary with this integer immediately produced the flag.
