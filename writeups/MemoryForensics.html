Memory Forensics — Practice

Context: Preparing for Bitdefender CTF, I wanted to train in forensic analysis using memory images.

Volatility3 Overview

Unlike Volatility2, Volatility3 requires specific commands for each OS. There is no longer an imageinfo command.

Detecting OS

I ran:

python3 vol.py -f Snapshot6_1609157562389.vmem windows.info

Output:

NTBuildLab 7601.17514.amd64fre.win7sp1_rtm.

This indicates a Windows 7 SP1 system.
