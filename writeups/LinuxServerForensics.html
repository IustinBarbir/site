Linux Server Forensics

First ssh into the machine using the given credentials

How many different tools made requests to the server?

access.log is a pretty big file, but it is easy to notice the first tool - dirbuster. For the rest, I tried using grep to look for tools

grep "nmap" access.log

This would also answer the next question:

Name a path requested by Nmap

I simply looked at the all the results that contained Nmap, since there were not so many of them. However, a more elegant solution would have been

cat access.log | grep nmap | cut -d ‘“‘ -f 2 | sort | uniq

Next I had to look at the actual website.

As the question suggests, contact.php allows users to upload files to the server
